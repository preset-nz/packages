# @preset.nz/property-editors

Shared substrate for inspector/properties panels across preset.nz apps: schema-as-data `FieldDef`s, a `Scope` that bundles schema+read+write, an open field-renderer registry keyed by `kind`, and a generic `<PropertyPanel>` that renders whatever scope is active. No app owns the panel's layout logic; each host contributes scopes and (optionally) custom field kinds. See the architecture writeup in the preset.nz guidance repo (`design/property-editors.md`) for the full rationale and the extraction discipline this package follows.

This package is distributed as **unbuilt TypeScript/TSX source**, consumed directly by each host's own bundler and `tsc`. That's deliberate: the built-in renderers import shadcn primitives via the conventional `@/components/ui/*` path, and each consumer supplies its own copies (built on whichever primitive library it prefers — Base UI, Radix, or otherwise) at that alias. Treat `react` and the shadcn primitive set as peer dependencies; there is no build step and no compiled output to consume. Add it to a consumer via a `file:` (or later, workspace/published) dependency pointing at this directory, and make sure the consumer's own `@/*` path alias resolves to its `src/`.
